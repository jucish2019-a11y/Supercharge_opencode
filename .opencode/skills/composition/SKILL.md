## What I do

I design visual compositions where every element has a reason for its position and the eye is guided intentionally — the difference between a page that feels designed and a page that feels assembled:

- **Dominance** — Establishing one element that commands attention first
- **Similarity** — Using visual consistency to create groups and relationships
- **Rhythm** — Creating predictable patterns that the eye can follow
- **Texture** — Using density variation to create visual interest and contrast
- **Direction** — Guiding the eye along intentional paths
- **Contrast** — Making important things stand out by making unimportant things recede

## When to use me

Use this skill when:
- A page feels cluttered or chaotic despite having good individual components
- Everything on the page feels equally important (or equally unimportant)
- You need to arrange multiple elements on a single page or screen
- A design looks "assembled" rather than "composed"
- All sections on a page look the same — same size, same spacing, same weight
- You're tempted to "just center everything" or "put it in cards"

## How I work

### Checker mode (auditing existing composition)

1. **Scan for dominance** — What do you see first? If multiple elements compete, dominance is missing.
2. **Trace the eye path** — Where does your eye go from the dominant element? Is it guided or scattered?
3. **Check grouping** — Are related items visibly near? Are unrelated items visibly separate?
4. **Map density** — Are some areas dense and others sparse? Or is everything evenly distributed?
5. **Test contrast levels** — Can you identify 3 distinct contrast levels (high, medium, low)?
6. **Look for rhythm** — Is there a predictable pattern of heavy/light, dense/sparse?

### Applier mode (composing from scratch)

1. **Choose the dominant element** — The one thing every viewer must see first.
2. **Arrange secondary elements** — They support the dominant element, never compete.
3. **Create groupings** — Near things are related. Far things are separate.
4. **Vary density** — Dense areas for focus, sparse areas for breathing.
5. **Set direction** — The eye should move naturally: dominant → secondary → tertiary.
6. **Add contrast only where needed** — Every accent weakens every other accent.

## The six principles of composition

### 1. Dominance

**Principle:** Every view needs one thing that commands attention. Not two. One.

The dominant element is what you see in the first half-second. It sets the context for everything else. Without it, the eye doesn't know where to land and scans randomly.

```
DOMINANCE HIERARCHY:

Level 1 — THE dominant element
  What: The single most important visual element on the page
  How: Largest size, heaviest weight, highest contrast, most space around it
  Example: A hero headline, a key metric, a featured image

Level 2 — Supporting elements (2-3)
  What: Elements that support and contextualize the dominant one
  How: Medium size, regular weight, moderate contrast
  Example: A subheading, a description, a secondary stat

Level 3 — Tertiary content (many)
  What: Navigation, metadata, footnotes, fine print
  How: Small size, lighter weight, lowest contrast
  Example: Timestamps, category tags, footer links
```

**How to establish dominance:**
- Size: make it 2-3× larger than the next element (use the type scale ratio)
- Weight: bold or semibold when everything else is regular
- Color: accent color for the dominant element, neutrals for everything else
- Space: generous whitespace around the dominant element isolates it
- Position: top-left (F-pattern) or center (Z-pattern) for maximum visibility

**The dominance test:** Squint at the page. What do you see? If multiple elements compete for attention, there's no dominant element.

### 2. Similarity

**Principle:** Things that look similar are perceived as related. Use this to group, or break it to separate.

Similarity creates groups without borders, backgrounds, or explicit containers. This is the most powerful grouping tool after proximity.

```
SIMILARITY SIGNALS:

Same size = same level of importance
Same color = same category or action type
Same weight = same hierarchy level
Same font = same content type (heading, body, caption)
Same shape = same interaction affordance (all buttons are rounded rectangles)

Break similarity to break grouping:
  Different size = different importance
  Different color = different category
  Different shape = different interaction (button vs link)
```

**Common similarity mistakes:**
- All section headings are the same size → user can't tell which section is most important
- All CTAs are the same color → user can't tell which action is primary
- All cards have the same layout → user can't tell which card is most relevant
- Fix: Make the most important item different. ONE item breaks similarity to create emphasis.

### 3. Rhythm

**Principle:** Predictable patterns create comfort. Breaking patterns creates emphasis.

Rhythm is the repetition of visual elements at regular intervals. Without rhythm, a page feels chaotic. With rhythm but no variation, it feels monotonous.

```
CREATING RHYTHM:

Repetition: Same element type appears at regular intervals
  - Section headings every 300-500px of scroll
  - Card items in a consistent grid
  - Paragraph spacing that's the same throughout

Rhythm with variation: The pattern repeats, but one element breaks it
  - All sections have the same heading style EXCEPT the hero
  - All cards have the same structure EXCEPT the featured card
  - Regular paragraph spacing EXCEPT before the conclusion
```

**Types of rhythm:**
- **Regular rhythm** — Identical spacing between identical elements (list items, grid items)
- **Flowing rhythm** — Gradual change in spacing or size (large hero → medium section → small detail)
- **Progressive rhythm** — Elements grow or shrink systematically (type scale, spacing scale)

**Rhythm in practice:**
- Section spacing should follow a pattern: larger breaks before more important sections
- Card grids should be regular, with one featured card that breaks the pattern
- The type scale IS a rhythm — each heading level is predictably larger

### 4. Texture (density variation)

**Principle:** Dense areas attract attention. Sparse areas give relief. Both are necessary.

Texture in composition means the density of information — how much visual weight occupies a given area. A page with uniform density is flat. A page with varied density has depth.

```
DENSITY LEVELS:

High density (attracts attention):
  - Hero section with large text and a CTA
  - A data table with many columns
  - A pricing card with many features listed
  - Navigation with multiple items

Low density (creates breathing room):
  - Whitespace between sections
  - A quote with generous margins
  - A single stat with large numbers and a small label
  - The space around a CTA button

DENSITY CONTRAST PATTERNS:

Pattern 1: Dense hero → sparse content → dense footer
Pattern 2: Sparse intro → dense middle → sparse outro  
Pattern 3: Dense sidebar → sparse main content
Pattern 4: Dense header → alternating dense/sparse sections
```

**The density test:** Step back from the page. Where is the dense area? Where is the sparse area? If density is uniform throughout, the page lacks composition.

### 5. Direction

**Principle:** The eye moves along paths. Create intentional paths, not obstacles.

Direction is the implied line that the eye follows from one element to the next. Without direction, the eye bounces randomly.

```
COMMON EYE DIRECTIONS:

F-PATTERN (content-heavy, text-dense pages):
  1. Horizontal scan across the top (header area)
  2. Second horizontal scan below (subheading or hero area)  
  3. Vertical scan down the left side (main content)
  
  Use for: Articles, documentation, blogs, dashboards with sidebar
  
Z-PATTERN (visual, less text pages):
  1. Top-left to top-right (header → CTA)
  2. Diagonal down to bottom-left (hero → supporting content)
  3. Bottom-left to bottom-right (secondary CTA → footer)
  
  Use for: Landing pages, hero sections, simple pages with one action

INVERTED-PYRAMID (important content first):
  1. Most important content at top, centered
  2. Supporting content spreads wider below
  3. Least important content at the bottom
  
  Use for: Marketing pages, announcements, news articles
```

**Creating direction:**
- **Alignment creates lines** — left-aligned text creates a vertical line the eye follows
- **Size progression creates flow** — large → medium → small pulls the eye down and across
- **Color accents create waypoints** — the eye jumps between accent-colored elements
- **Images create gaze direction** — a face looking left draws the eye left; an arrow pointing down draws the eye down
- **Whitespace creates pauses** — generous space before an important element makes the eye stop and register it

### 6. Contrast

**Principle:** Important things stand out because unimportant things recede.

Contrast is the compositional tool that makes dominance work. You can't have a dominant element without making everything else subordinate.

```
CONTRAST LEVELS (use at least 3):

High contrast (dominant):
  - Largest text on the page
  - Accent color on neutral background
  - Bold weight when everything else is regular
  - Generous whitespace isolation

Medium contrast (supporting):
  - Section headings (scaled but not the largest)
  - Primary color for secondary CTAs
  - Semibold weight for labels
  
Low contrast (subordinate):
  - Body text in medium-contrast neutral
  - Light-weight metadata, timestamps
  - Border colors, background fills

CONTRAST MISTAKES:

Too much contrast everywhere:
  - Every heading is accent-colored → nothing stands out
  - Every section has a different background → no rhythm
  - Every button is large and bold → no primary action

Too little contrast:
  - All text is the same size → no hierarchy
  - All sections have the same spacing → no grouping
  - All colors are muted → nothing catches the eye
```

**The contrast hierarchy (ordered by power):**
1. White space (most powerful — creates separation and emphasis)
2. Weight (bold vs regular — creates hierarchy within text)
3. Size (large vs small — creates visual levels)
4. Color (accent vs neutral — creates focal points)

Use color as a contrast tool sparingly. When everything is accent-colored, nothing is.

**Typographic contrast levels:**

Each hierarchy level must be clearly distinguishable from the next. Use at most 2 font weights (regular + semibold/bold) and 4-5 font sizes per page:

| Level | Font Size | Font Weight | Color |
|-------|-----------|-------------|-------|
| H1 — Page title | 28-32px | 700 | --text-primary |
| H2 — Section title | 20-24px | 600 | --text-primary |
| H3 — Subsection | 16-18px | 600 | --text-primary |
| Body — Main content | 14-16px | 400 | --text-primary |
| Secondary — Descriptions | 14px | 400 | --text-secondary |
| Caption — Metadata | 12-13px | 400 | --text-tertiary |

**The 3-second test:** If you can't tell what's most important in 3 seconds, the hierarchy is wrong. Squint at the page — if the visual priority order isn't obvious, the composition needs work.

## Common composition patterns

### The editorial layout

```
┌─────────────────────────────┐
│                             │
│  LARGE DOMINANT HEADLINE    │  ← Dominance: size + weight + space
│  Supporting subtext         │  ← Medium contrast
│                             │
│  ─────────────────────      │  ← Rule creates rhythm break
│                             │
│  Body text in content       │
│  column at 2/3 width.       │  ← Direction: F-pattern in column
│  Sidebar at 1/3 width.      │
│                             │  ← Density: text is dense, 
│                             │     sidebar can be sparser
│                             │
│  ─────────────────────      │
│                             │
│  Footer metadata            │  ← Low contrast
└─────────────────────────────┘
```

Character: Authoritative, text-forward, structured
Good for: Articles, documentation, long-form content

### The feature layout

```
┌─────────────────────────────┐
│                             │
│  ┌───────────┐ FEATURED     │  ← Dominance: featured card breaks
│  │           │  ITEM        │     the pattern, gets more space
│  │  LARGE    │              │
│  │  FEATURED │  Supporting  │  ← Medium contrast: supporting items
│  │  ITEM     │  text and   │     flank the dominant one
│  │           │  metadata    │
│  └───────────┘              │
│                             │
│  ┌────┐ ┌────┐ ┌────┐      │  ← Rhythm: regular grid BUT
│  │    │ │    │ │    │      │     the featured card above
│  └────┘ └────┘ └────┘      │     breaks the pattern
│                             │
└─────────────────────────────┘
```

Character: Product pages, feature showcases
Good for: Feature lists, product catalogs, team pages

### The stat layout

```
┌─────────────────────────────┐
│                             │
│  ┌─────────────────────┐   │  ← Dominance: ONE large stat
│  │     75%              │   │     with generous space around it
│  │  of users agree      │   │
│  └─────────────────────┘   │
│                             │  ← Density contrast: sparse
│  ● Bullet point one        │  ← Rhythm: regular list items
│  ● Bullet point two        │     with consistent marking
│  ● Bullet point three      │
│                             │
└─────────────────────────────┘
```

Character: Data-driven, editorial, authoritative
Good for: Statistics, key metrics, proof points

## Composition audit checklist

```
COMPOSITION AUDIT

DOMINANCE:
[ ] One element is clearly the first thing you see
[ ] The dominant element is 2-3× larger than the next element
[ ] No two elements compete for equal attention
[ ] The dominant element has the most whitespace around it

SIMILARITY:
[ ] Related items look similar (same size, weight, color)
[ ] Unrelated items look different
[ ] Exactly ONE item breaks the pattern for emphasis
[ ] All CTAs are similar, EXCEPT the primary CTA

RHYTHM:
[ ] Section spacing follows a pattern (not all equal)
[ ] The pattern has at least one variation for emphasis
[ ] Type sizes follow the type scale (no magic numbers)
[ ] Card grids have a featured item that breaks the pattern

TEXTURE:
[ ] The page has both dense and sparse areas
[ ] The densest area is near the dominant element
[ ] No area is uniformly dense (no "walls of text")
[ ] Stepping back reveals clear density contrast

DIRECTION:
[ ] The eye path is predictable: dominant → secondary → tertiary
[ ] Alignment creates consistent lines (left edges, horizontal rules)
[ ] The F-pattern or Z-pattern is used intentionally
[ ] No element forces the eye to jump backwards

CONTRAST:
[ ] At least 3 contrast levels are visible (high, medium, low)
[ ] Color is used sparingly for accent only
[ ] White space does most of the grouping work
[ ] Removing any accent color doesn't break the hierarchy
```

## Anti-patterns I avoid

- Centering everything — creates no alignment axis, forces the eye to find each starting point
- Giving every section equal visual weight — hierarchy means some things are more important
- Putting every content type in a card — not everything needs a container; use whitespace and similarity instead
- Using color as the primary hierarchy tool — color is the least accessible and least reliable hierarchy signal
- Uniform section spacing — "the same gap" means "the same importance," which is almost never true
- Multiple visual focal points — if everything is highlighted, nothing is highlighted
- Ignoring the squint test — if you can't see the hierarchy when you blur your eyes, it doesn't exist
- Adding visual interest through decoration (glassmorphism, gradients, drop shadows) when composition should do the work
